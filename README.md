# Home Workout Menu Builder

A personal home workout menu builder focused on **dumbbells**, with quick toggles for **Weight Bench** and **Barbell**, articulated exercise movement guides, custom routine saving (`localStorage`), and a built-in rest timer.

## Local Development

```bash
npm install
npm run dev
```

## Deploy to Vercel

### Option 1: GitHub + Vercel Dashboard (Recommended)
1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Vercel will auto-detect **Vite** (`npm run build`, output directory `dist`) — just click **Deploy**.

### Option 2: Vercel CLI
```bash
npm i -g vercel
vercel --prod
```
